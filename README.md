# DevOps-Lab04

## เกี่ยวกับโปรเจกต์

FixFlow เป็นเว็บไซต์ตัวอย่างสำหรับบริการ IT Support ช่วยให้ผู้ใช้งานดูบริการ แจ้งปัญหาเบื้องต้น และเข้าใจขั้นตอนการรับเรื่องได้ในหน้าเดียว

## ฟีเจอร์

- แนะนำบริการด้านคอมพิวเตอร์และอุปกรณ์ เครือข่ายและอินเทอร์เน็ต รวมถึงโปรแกรมและบัญชีผู้ใช้
- อธิบายขั้นตอนการแจ้งปัญหา ตั้งแต่ส่งรายละเอียดจนถึงการแก้ไขและปิดงาน
- มีแบบฟอร์มสำหรับกรอกชื่อ อีเมล ประเภทปัญหา และรายละเอียด
- รองรับการแสดงผลบนหน้าจอขนาดต่าง ๆ

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง โปรเจกต์นี้เป็นเว็บไซต์แบบ static และไม่ต้องติดตั้ง dependencies หรือ build ก่อนใช้งาน

> **หมายเหตุ:** แบบฟอร์มเป็นตัวอย่างเพื่อสาธิตการใช้งานเท่านั้น ขณะนี้ยังไม่ได้เชื่อมต่อ backend หรือระบบจัดเก็บและส่งคำขอจริง
